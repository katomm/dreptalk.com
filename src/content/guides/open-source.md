DRepTalk is open source, released under the **Apache 2.0** license.
The entire codebase is public on
[GitHub](https://github.com/katomm/dreptalk.com), so anyone can read how the
platform works, audit how on-chain data and wallet sign-in are handled, and run their
own copy. For a forum built around Cardano governance, that transparency is the point.

## Contributions are welcome

We would love your help. Found a bug, spotted a wrong status, or have an idea that
would make the forum better? Open an issue or a pull request on
[GitHub](https://github.com/katomm/dreptalk.com). Documentation fixes, design
feedback, and translations are just as valuable as code. If you are unsure where to
start, open an issue describing what you have in mind and we will help you scope it.
