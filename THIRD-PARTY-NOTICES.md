# Third-party notices

DRepTalk bundles third-party open-source software and fonts. This file reproduces
the attribution notices those licenses require.

Scope: what we ship to visitors, meaning the browser bundle and the files in
`public/`. Dependencies that only run at build time or inside the Worker are not
listed here.

## cip-179

Building blocks for CIP-179 on-chain surveys: the label-17 metadatum codec, the
domain semantics behind a survey's lifecycle and tally, and the record decoder
the survey panel runs in the browser. Licensed under the Apache License,
Version 2.0.

- Homepage: https://github.com/mpizenberg/Tessera/tree/main/packages/cip179
- License: https://www.apache.org/licenses/LICENSE-2.0

    Copyright 2026 Matthieu Pizenberg and Tessera contributors
